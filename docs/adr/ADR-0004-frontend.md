# ADR-0004: Frontend

Status: Akzeptiert, konsolidiert am 2026-10-28.

Verbindlicher Stack: React, TypeScript, Vite, TanStack Query, React Router, Tailwind CSS, Lucide Icons, Leaflet (Karten) und Recharts (Diagramme). Details in [RFC-0006](../rfc/RFC-0006-frontend-architecture-and-pwa.md) und [RFC-0020](../rfc/RFC-0020-maps-and-visualization.md).

PWA installierbar, HTTPS, keine dauerhafte Offline-Trainingskopie in V1. Verbindung zum TrackCraft-Rechner erforderlich, externe Karte benötigt zusätzlich Internet. Siehe RFC-0006/RFC-0020.
